DESIGNER REPORT — `an-undecided-at-rest-decision-climbs-the-ladder-on-a-margin-that-is-not-zero`

## For Ev

**Recommendation.** Give "no" a proof of its own, and take it from the value side, because the symbolic tier cannot produce one. Where a decision's box reading shows no definite sign at an exact-witness symbolic scalar (`Sym<Interval>`), read the margin's expression once more at **one named point of the leaf's box** (each parameter at a point of the bracket the session already holds, every op in outward-rounded intervals). A definite sign there proves the margin is not an identity over the box, so the tier is asked nothing. The decision stays undecided, exactly as today. Only where the point reading also holds zero is the ladder climbed, as today. Confidence: **likely** (the argument is sure; that the point reading refutes these four margins is unmeasured).

**Terms.** *Margin*: the number a decision takes the sign of. *Tier*: the symbolic machinery of E12 that proves a margin zero as an identity. *Ladder*: its sequence of normal-form attempts (plain form, early walk, top reduction, registered-identity door, then two retries under other rule sets). *Form*: a node's polynomial normal form. *Atom*: a `sqrt`, trig or frozen sub-expression the form treats as an unknown. *Leaf*: one box of the driver's subdivision. *Exact witness*: a scalar whose comparisons are certified over the whole box (`Interval`).

**Premise check.**
1. The item asks what the ask should cost when the answer is "not an identity". The tier has no such answer and cannot have one: a residual form that is not the zero polynomial proves nothing, because its atoms are unknown functions (E12: "an atom is an unknown function") and may still cancel. "Ran out of attempts" is silence, the same silence an unproved true identity gets. So the cost is unbounded by construction: every rule set must be tried before giving up. The missing part is a refuter, not a cheaper ladder. (sure)
2. The question E12 poses is "is this margin zero at every parameter point of the box at which the build takes this replay's decisions". A certified nonzero reading at one such point answers it "no", completely. At an exact witness every definite decision of the replay holds at every point of the box, so any point of the box is such a point. (sure; this is the same isotonicity argument `discharge_checked` already makes for its debug assertion that a proven zero's enclosure holds 0)
3. E12 already orders the channels this way over the whole box ("a decision reads the value first and asks the tier only where the value reads no definite sign"). The four margins fail that test only because a whole-box interval reading suffers dependency widening; a point reading does not (its width is rounding only). The recommendation is that sentence applied at a second, narrower reading. (sure)
4. The largest asker cannot use the answer it asks for: `Foot::on_carrier` accepts only `Positive` from `curve_carrier_clear`; a `Zero` there ends in the same refusal as undecided. That is 683 s of the 983 s. It is evidence of the defect, not the fix: the probe measured that silencing askers by name moves the cost to the next one. (sure, read in the code and in M11 item 5)

**What it makes true (final state).**
- *What the question is a function of:* the expression graph and the leaf's parameter brackets, which are the only values the tier reads today (`Sym::param_over`'s record). The point is a function of the box alone, so the answer is deterministic and the same on any schedule. It should sit off the box's centre and corners: a root box is centred on the nominal, and a coincidence at the nominal (E12's collinear-at-p₀ case) reads zero exactly there.
- *What "no" is:* a certified sign at a point. It changes no decision: if the tier is sound, a margin refuted at a point is one the ladder would have left unproved. Verdicts, the symbolic/numeric counts and the K record are unchanged; the `frozen` column falls (fewer forms are built), as the probe's skip experiment already showed (1,490 to 658 with every verdict the same). (sure, given tier soundness)
- *What each stage and retry buys:* unchanged, but only for margins that could be identities: true identities, margins that vanish at the chosen point, and margins whose graph reaches a value with no expression (an iterated quantity, a hull, a free variable), where the point reading declines. The ladder's rules, order and budgets are not touched. (sure)
- *Where answers live:* a `Zero` where it lives now (forms per leaf, plain forms per drive). A "no" lives as the point value of each node, memoised for the leaf, because it is a function of the box. Nothing new is kept per drive. (likely)
- *What the caller and the driver are owed:* the same undecided answer as today, at the price of one arithmetic pass over the nodes under the margin (shared between margins through the per-node memo) instead of thousands of forms. Expected cost per leaf is of the order of the replay's own arithmetic. (likely, unmeasured)
- *Signature:* at `Sym<Interval>` the point reading exists. At `Sym<f64>` and the probe scalar the value already is a point reading, so there is nothing to add and the tier is asked as today.

**Worked example.** The pose discriminant reads `[-4.87e-8, 1.01e-7]` over a 0.1 mm box because the ray's offset reads 56 times the box wide. At one point of the box every input is a point, the offset is a point, and the discriminant reads about 0.49 mm with rounding-width error: definite, so no ladder (today: 113 ms and 10,796 forms, to say nothing). The decision still returns undecided and the ray is still set aside.

**The per-drive store and the shared forms.** The store (one node result per drive, already approved) is untouched and multiplies with this: the probe found each hole key repeats about 8 times, so the store cuts how many hole finishes run, and the point reading cuts what each one that runs pays. The forms the undecided margins share are simply not built for a refuted margin, so there is no cross-margin sharing to design. (likely)

**Other answers, and why not.**
- *Ask only where the caller can use `Zero`* (a positive-only site does not ask). Right for `curve_carrier_clear` as a statement of what that site wants, but measured to move the cost rather than remove it, and at a gate a proven `Zero` is real information (no narrower box will ever pass). Not the cure.
- *Keep negative results or early forms per drive.* The early walk reads the box (the certified arm at `min`/`max`/`select`), and a narrower box can prove more, so a parent's silence does not bind its children; it would divide the price where the recommendation removes it. Rejected.
- *A smaller budget or fewer retries for at-rest asks.* Trades identities for time on a dial, and still pays on every nonzero margin. Rejected.

**Ratified text.** E12 is not what makes this hard; it is one sentence short. Its value-first sentence was agent-written (commit `eca9909b90`, 2026-11-15, a fork's recommendation), and nothing here contradicts it. Proposed addition to E12's bullet "The two channels are checked where an answer is returned", after "the tier is asked nothing about it":

> Where the box reading is undecided at an exact witness, the margin's expression is read once more at one named point of the box. A definite sign there proves the margin is no identity over the box: the tier is asked nothing and the decision stays undecided.

Reversible: yes, it is one early return ahead of the ladder.
