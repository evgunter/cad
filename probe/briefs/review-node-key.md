## What the change is
The evaluator reuses a node's result when its content key matches. At a symbolic scalar the key hashed a value's number and not its expression, so two inputs with equal numbers and different expressions shared a key; and a value with no expression (`Sym::opaque`) was named by a counter that restarted with each session, so two replays could give one name to two numbers. The PR feeds the expression's node id into the key at `Sym<T>`, and names a value with no expression by a "mint scope" the evaluator opens per node (a hash of the scope's ancestry) and its ordinal there (`geom-core/src/sym/mint.rs`). It says no verdict, receipt count or `frozen` set moves, re-cuts one pin, and files the inputs a node reads that the key still does not hash.
