## What the change is
A drive certifies a document over a box of its variables by bisecting the box into leaves and replaying the build in each. An undecided leaf used to be split along the box's relatively widest variable. The PR makes `classify_replay` return the deciding node (`LeafVerdict::Bisect { deciding }`), computes each node's read set from the document (`Doc::free_reads()`), splits only along a variable that node reads (`drive::bisect`, `ParamBox::split_axis(root, among)`), and refuses at once, with a new typed reason `RefusalReason::ReadsNoVariable { node }`, a leaf whose deciding node reads no variable of the box. On main the tour's drives do not move; a two-parameter plate's drive certifies more with fewer replays; a loft drive that bisected to 256 `Budget` leaves becomes one refusal.
