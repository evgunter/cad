**1. The normal's choice of sides: the select is gone.** I could not build a row that reds under `let n = ab.cross(bc)`, and found why. With the corners in one order, the first two sides are a needle's two long sides only when the far corner sorts between the close two, which puts the needle across the first coordinate to within its own width; the one component of the product that cancels is then that coordinate's, and its rounding tilts the plane about the needle's own length, where the foot is within a width. Measured: worst 3.3e-15 of a unit length over 20 000 needles (widths 1e-9 to 1e-4) built so the fixed pair is long × long. So `cert.rs:131` is `let n = ab.cross(bc);` with that argument as its comment (`:125-130`).
