# QA-9 — the status line that invites wrong action (#1139)

Unit spec, S-QA program (`docs/S-QA-PLAN.md` §QA-9). Binding
alongside `docs/prompts/implementer-discipline.md`. **Read issue
1139 in full first** — it carries the incident (an orchestrator
read "flock is free — safe to acquire" about a slot its shared
waiter structurally cannot poll at width 1, and issued a wrong
kill instruction that the lane correctly refused) and the fix
shape. Verify the premise at your merge base:
`local-scripts/with-build-slot.sh`'s queue status annotation
(~:188) and the width-gated shared-mode polling (~:231-238).

## Deliverables

1. The annotation becomes RELATIVE TO THE READER, per the issue's
   own suggestion: the wrapper knows its `$MODE` and `$WIDTH`, so
   the stale-holder line says which of the three states it means —
   free-and-reachable for this request; free but unreachable at
   this width (exclusive-only slot); genuinely held by <pid/cmd>.
   Or omit "safe to acquire" entirely for slots the current
   request will never poll — your call, argued in one sentence at
   the site. A line a waiter cannot act on is worse than no line.
2. Every OTHER reader-facing status line in the script gets the
   same one-question audit while you are there: can the reader of
   this line act on it as written, at every (MODE, WIDTH)? Fix or
   disposition each in the PR body — this is the sweep rule, the
   file is small.
3. Red-first where testable: the script has selftest machinery or
   is testable by invocation — demonstrate the old misleading line
   and the new one at width 1 shared (a synthetic stale holder
   file + a dead pid is cheap to construct in a temp
   `CAD_WORK`-shaped dir; check how the script locates its lock
   dir and override it for the test rather than touching the real
   one).

## Out of scope / fences

The locking semantics themselves (width, express lane, queueing) —
this unit changes only what the STATUS OUTPUT says; `disk-watchdog`
and the other local-scripts (qa/6 is sweeping them read-only);
anything outside `local-scripts/`. Issue 1139 closes by the
orchestrator.
