# PR 7291: a number in a unit is rounded once over the unit's exact factor

**Unit:** the build of changes 1 and 3 of the ruling on PR 7261 ("A number told to a person", `crates/geom-core/README.md`): a number written in a unit is the float nearest its decimal times the unit's exact factor (true π), rounded once, at the text, Rust and Python doors; every unit says every quantity, so the fallback to the canonical unit goes; equality of a told quantity is a plain derive.

**Letter and tier:** H, dual: new exact arithmetic (an in-tree big natural, correct rounding, an extendable π) under every door a unit-bearing number enters by. Logged in the unit's item file before the draws. Concurrent pair (H).
