# PR 7704: the shape report writes one decision's texts within a stated budget, and names what it leaves out

**Unit:** BOXFINISH, `a-boxed-rectangles-certification-runs-out-of-memory-with-the-box-arm-off`: the symbolic tier's shape report rendered a blocking form with a nesting limit and no limit on breadth, re-spelling each atom at every site, so a text grew as the fan-out to the fifth power (16.7 MB for a 241-node form) and a boxed rectangle's replay ran out of memory with the switch's box arm off. One decision's three texts now take at most 768 KiB, a third each; a form past its share is written at the deepest nesting that fits, with each unspelled atom named, and a text that is cut says what it leaves out.

**Letter and tier:** L, single STYLE review: it bounds what a diagnostic renderer writes and decides nothing, so the change can be read and believed; what a review adds is whether the bound has one home and its rows can fail. Both were logged in `work/boxfinish/log.md` before the draw.
