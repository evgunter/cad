# PR 7143: oneround/lever-doors: curvature arms read their carrier, and a gate pins every lever door that takes a caller's number or point

**Unit:** one ONEROUND row: a `Lever` could carry any length a caller wrote through its geometric constructors, against the README's "never from a length a caller vouches for" (Ev's ruling on PR 6380: keep the text, fix the violations). The PR reads 40 of 46 curvature arms off their carrier, makes `Lever`'s field private, and adds a gate that pins every named door taking a caller's number or point. Its own body says the README's sentence is not made true: 59 references stay pinned, and the residue is filed. The row closes; four rows carry what is left.

**Letter and tier:** M, single, a FULL review: "no production site can build a lever from a length it wrote" is a claim a reviewer falsifies by building one, as PR 6391's review did six ways. Logged in `work/oneround/log.md` before either draw (`ac779283` on `oneround/orchestrator`).
