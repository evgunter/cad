# PR 7393: an iso image stores the line it holds and one map along it, and no ends

**Unit:** BOXFINISH, `an-iso-line-states-its-ends-twice-as-its-map-and-as-stored-ends`: the design ratified on `[ev]` PR 6975 (fork 271). A chart image along a row or column of its chart stores the line it holds as structure and one map along it; the stored ends, the span type and the checks that kept them in step with the map are gone. A corner is the lift's (the meet of two held lines), and a closed chart's period is its domain's two ends.

**Letter and tier:** M, dual (sequential): it changes a stored type every chart reader touches, across `geom-brep`, `topo`, `sweep` and the importer. Both were logged in `work/boxfinish/log.md` before the draw.
