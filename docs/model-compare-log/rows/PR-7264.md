# PR 7264: an adjacent line pair's shared vertex is a contact by construction, so a boxed rectangle validates

**Unit:** a rectangle drawn with the pen whose one side is a parameter with a box refused at validation with a line/span refusal over any box. Two adjacent lines share their vertex by construction, and the pair pass recomputed that vertex as a root of the two carriers and could not order it over an interval. The pair pass now reads the shared end as a contact (`SharedEnds`, `CKind::SharedVertex` in `line_line`) and does not recompute it.

**Letter and tier:** M, single. Logged in `work/profile/log.md` as a FULL review at dispatch: the change moves which crossings every line pair reports, which is more than reading it can settle.
