# PR 7512: a node's keys hash what each read sees, and a prior run under other options is refused

**Unit:** BOXFINISH, `a-family-members-read-of-another-member-is-served-from-a-prior-that-read-its-old-body` (P0): a family member's read of another member was keyed by the value that stood in the results, not by what the read sees, so an evaluation served from a prior could hand back a result that had read the other member's old body. A node's content and naming keys now hash what each read sees (the member an index picks, the family read whole), the clearance's rebuild and the read's variable; a prior run under another twist, sweep or symbol setting is refused at the door.

**Letter and tier:** M, single FULL: a key that leaves something out serves a stale result silently, so the review carried the correctness claims. Both were logged in the unit's file before the draw.
