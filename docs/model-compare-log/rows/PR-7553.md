# PR 7553: the plane arm's belly is read to the gap's own digits for far-centred conics

**Unit:** GERM, `the-plane-arms-harmonic-amplitude-rounds-at-a-far-centred-conics-reach` (P1, M). This was the review's M1 finding on PR 7411.
- **The defect:** the plane arm decided a conic's belly `r − |d₀|`. For a conic centred far from the arc that a plane grazes, the two terms cancel down to a gap the size of the band. Wrong signs went through uncharged.
- **The fix:** a new door, `Conic::belly_along(o, n)`, in `conic.rs`. It reads the conic's stored placement and forms `B` exactly. A new `Real::harmonic_belly` computes `(A²+B²−d₀²)/(√(A²+B²)+|d₀|)` with an exact-expansion numerator.
- **Same fix applied in four more readers:** `line_conic`, the `conic_conic` screen, `transverse`, and topo's `line_clears_conic`.

**Letter and tier:** M, single FULL. The unit re-poses a cancelling formula, so its conditioning had to be shown against an exact oracle rather than read. Both were logged before the draws.
