## Quality of the implementation

**R1's verdict:** MERGEABLE-AFTER-MINORS, with 0 MAJOR, 2 MINOR, 2 NOTE and a style section.

**What R1 confirmed:**
- **The door holds:** `Reversal` is private and built by an exhaustive match, and every split in `reverted()` goes through it.
- **The answer is unchanged on every arm:** `charts_agree` is a parity of its three inputs. For a plane under ∖ the new code flips the relation where the old code flipped the sense. For every other kind it flips both, which cancels.
- **R1 demonstrated by mutation** that the curved ∖ row is real: feeding B's unreverted sense turns it red, and so does dropping the relation flip.

**MINORs:**
- a dangling surface link silently dropped the token; it now fails loud;
- the `worn` fix changed behaviour in one case without showing which side was right. It was reverted: the doc was the wrong side, and no row could reach the case.

**NOTEs:**
- "a chart-carrying surface is a plane" was written twice inside the door. `Reversal::Chart` now carries the reversed chart, so the second match and its `unreachable!` are gone.
- tests outside the door restate the convention by pinning revert's output. That is acceptable as written, and they are the rows to sweep if the convention ever changes.

**Style:** a closure became a method; the doc now says `b` must be the pristine operand; the NURBS fixture asserts its kind; the test name matches its file. All taken.

**Rubric:**
- **Idiom and structure: 4.** The spec landed as designed, and the fix pass made the door carry its data rather than re-match.
- **Test quality: 4.** The door rows cover three kinds, and the curved ∖ row is proven by mutation.
- **Doc and comment honesty: 3.** At the frozen head the `worn` change was argued but not shown, and the "one statement of the split" claim read broader than the code.

**Hosted CI:** kernel tests passed on both heads. The only reds were timing: rows a few milliseconds over the 1.0 s bar, in files this PR does not touch:
