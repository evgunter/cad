# PR 7646: the turn-defect fuzz compares its bound with a clamped sample

**Unit.** GERM, `turn-defect-speed-sup-bound-sits-one-ulp-under-an-interval-sample-at-the-ceiling`. It was P2, raised to P1 because a varying-seed row reds other programs' gates.

**What was wrong.** The fault was in the test's comparison, not in the kernel. Against a 60-digit oracle, `turn_defect_speed_hi`'s sup and inf are sound. Near a semi-axis the test's Interval sample overshoots the true speed by 7.4–12.3 ulps.

**The fix.** The test intersects its sample with the exact range `[min(a,b), max(a,b)]`, which holds because `|C′|²` is a convex weighting of a² and b². No kernel source changed.

**Letter and tier.** M, single FULL, logged before the draws, when the unit still looked like an unsound enclosure.
