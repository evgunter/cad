# PR 7327: a carrier's rate read square to its axis, so a reflex corner is read by its own carrier

**Unit:** EMBED's `a-cell-past-an-iso-edges-end-is-clipped-by-its-whole-line` (unit branch `embed/iso-end`), with the reflex corner on a curved chart and on a plane, which moved here from `embed/straight-corner` at dispatch. The lane measured before designing and found the defect one level up: `Psi::gradient` enclosed a carrier's gradient as a vector and then dotted it with the chart direction, losing that a cylinder's gradient is square to its axis. The fix is `Psi::rate(box, v)`, with the axial part of `v` removed for the cylinder and the cone's radial term. `geom` is untouched.

**Letter and tier:** M, single, a FULL review. Logged at dispatch in `work/embed/log.md` (21 Nov, 21:45Z).
