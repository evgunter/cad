# PR 7470: a node's content key at the symbolic scalar hashes the expression, and a value with no expression is named by the node that minted it

**Unit:** BOXFINISH, `a-nodes-content-key-at-the-symbolic-scalar-hashes-the-number-and-not-the-expression`: the first unit of the re-finish design Ev approved on `[ev]` PR 7368. At `Sym` a node's content key hashed the value's number, so two spellings of one number keyed alike and a prior over the other could be served. The key hashes the expression; a value with no expression (an opaque) is named by the scope that minted it and its count there, not by a per-thread sequence.

**Letter and tier:** M, single FULL: a key that says too little serves a wrong result silently, so the review carried the correctness claims. Both were logged before the draw.
