# PR 7492: a node's result at the symbolic scalar is its own, and reads no per-replay session state

**Unit:** BOXFINISH, `a-nodes-result-at-the-symbolic-scalar-reads-per-replay-session-state`: the last two of the four changes Ev approved on `[ev]` PR 7368. Every piece of the symbolic session is the drive's (the expression table, the plain forms, the atom records), a node's (its registry, its retry memos and guard, its counts) or a cache valid for the leaf; a node's value carries its record (`NodeRecord`), and a reader's scope opens over the records of exactly what it reads.

**Letter and tier:** H, dual (a concurrent pair): the symbolic session is the ground every tier-3 answer stands on, and the store unit builds on what this one says a result is. Both were logged in `work/boxfinish/log.md` before the draw.
