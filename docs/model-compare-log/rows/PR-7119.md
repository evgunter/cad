# PR 7119: a face pair that shares nothing is read apart in depth at its root

**Unit:** EMBED's P0 `nested-tori-a-thin-gap-apart-spend-the-pair-budget-on-box-distance` (unit branch `embed/nested-tori`), from the second engine wave.
