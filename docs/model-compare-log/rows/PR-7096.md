# PR 7096: a ruled face with a split side is walked, and meshes at the density of the face without it

**Unit:** TESSLANE, `a-ruled-face-with-a-split-side-meshes-at-the-density-of-the-face-without-it`: a cylinder or cone face whose straight side holds a split point took up to 196 times the triangles of the same face without the split (17,600 times on a needle cone) and refused where the split made nothing harder. The unit measured three cures, stopped for a ruling, and built one: the face is walked row against row, sized at δ, and has the unsplit face's triangles plus one per point its side gained.

**Letter and tier:** H, dual: the cure changes how the chart lane sizes and triangulates every cylinder and cone face it takes with a split side, each candidate adds a mechanism to that lane, and the count relation it must hold has no oracle but measurement. Both were logged in the unit's file (`14389dc621`) before the first draw.
