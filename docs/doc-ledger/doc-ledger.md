# DOC-LEDGER.md

`docs/DOC-LEDGER.md` — the one-file predecessor of this directory. It held
every entry below appended at a single anchor, which made it the
highest-collision file in the tree, and it carried the convention that now
lives in `memories/docs-ledger.md`.

Deleted 2026-09-22 on Ev's ruling, replaced by the notes beside this one.
Recover with `git show 26999f297:docs/DOC-LEDGER.md`, and read its whole
history — every entry as it was first written — with
`git log -p --follow -- docs/DOC-LEDGER.md`.

If you arrived here from a citation naming a numbered sweep, the numbers
are gone: three different sweeps shared the number 6 and three more shared
7, which is why the notes are named after what they deleted instead.
