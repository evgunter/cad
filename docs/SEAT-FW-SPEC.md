# SEAT-FW — the flush detector widens to the curved Rest rungs (unit spec)

Takes the fork SEAT-3 measured and deliberately declined
(`work/seat/flush-detector-widening-to-curved-rungs.md`, issue 1537):
`topo::flush::pair_finding` swaps `flush_pair_relation` for
`carrier_pair_relation` — a one-identifier change under which NO verify
table moves (`PlaneRelation` IS `CarrierRelation`, `PlaneEqError` IS
`CarrierEqError`; the anti-twin rule survives by construction) — and
the unit's whole substance is the content review that swap forces.
Faithful elaboration of SELECT-DESIGN's scope paragraph and
VERB-SEAT-DESIGN §1 S3; self-merges. A demo wall whose change cannot be
argued right is a reported fork, not a re-baseline.

## FW-1 — the swap and the seats it moves

The body seat's `find_flush_candidates` grows sphere/cylinder/torus
findings; the document door's `find_flush_candidates` (the derived
wrapper) grows them too — behavior SEAT-3 pinned planar-only, so the
pins move DELIBERATELY: every changed answer stated as (scene, wall,
old finding set, new finding set, why the new set is right). The
declared set a document ends up with is still the author's: the
detector proposes, `declare_all` declares — the no-fusion rule
(SELECT-DESIGN GS-Q3) is unchanged and its pin re-run.

## FW-2 — the demos, re-authored through the detector

`twopeg`'s eighteen hand-assembled cylindrical declarations (nine per
peg) collapse to detector findings + `declare_all`; `lily`'s socket
likewise. The lily's stem glue is PINNED on curved contacts refusing
today — that pin is the unit's scrutiny point: either the refusal was
the planar detector's blindness (then the wall changes and the render
is re-blessed with the removal measurement) or it is a real refusal the
verify ladder still gives (then the pin stays and the finding is
declined at the document with the refusal shown). Render lanes are the
record: byte-identical bodies where the declared set is the same set
by another road; a changed body only where FW-1's table says so.

## FW-3 — the prose

SELECT-DESIGN §3's scope paragraph: "planar" → the verify ladder's true
reach, stated per rung; `docs/KERNEL-VERBS.md`'s detector row; the
`seat3_measurements` block in `demos/tour/src/twopeg.rs` retires with
the measurement it recorded (the measurement is now the mechanism).
