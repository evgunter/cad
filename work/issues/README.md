# `work/issues/` — items no program owns yet

**This directory is for issues that do not have a home yet, not a
waiting room for issues whose owner is obvious.** When the owning
program is clear, file the item directly onto that program's slate
(`work/<program>/<id>.md`) — a lane does not need the owner's
permission to put a finding where it belongs. (Ev, 2026-09-04.)

An item here is claimed by MOVING it, header edit and `git mv`, never
by copying: see `work/README.md`, which is the contract this file only
points at.
