**What a person reads and types.** A number in a unit is rounded once
(PR 7291) and told in a role and a notation (PRs 7159, 7229); this
program holds what is left of that story. One row is not formatting:
a refusal's corner point is read as a number by the viewer and Python,
which is what the Python door exposes. The rest is how text reads, and
sits at P2 and below by Ev's direction of 2026-11-22 (skip or
downgrade work that is formatting with no design ramification): the
teller that makes a bare `{}` inside a `tell` body a compile error
(a gate holds the class today), the per-crate sweeps of `Display` arms
onto the told quantity, the kept refusal that keeps its text, the
vocabulary folds in `quantity`, and the readings of a float at the
Rust and Python doors.

Four questions wait to go to Ev together, none blocking: the README
states "never finer than the spacing of adjacent floats" for a computed
length and the code applies it to every role
(`never-finer-than-the-floats-for-every-role`); an offer a float under
a round number reads as the grid point below; a computed float through
`x * MM` is read by its shortest decimal; and whether `quantity`
staying a zero-dependency leaf is worth a second big integer
(`a-second-big-integer-beside-num-bigint`).
