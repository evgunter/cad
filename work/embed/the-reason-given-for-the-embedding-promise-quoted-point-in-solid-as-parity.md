## Finding

From a designer of fork `embed-records`, 2026-11-18, off the question.
**Read, not run.**

Ev's ruling on PR 6301 ("3 is fine indefinitely": a finished body's
boundary is embedded) followed the CLEAR orchestrator's reply that a
boundary crossing itself has no inside every reader agrees on, with the
point-in-solid door given as a reader that "counts ray crossings by
parity" and so reads a twice-swept region as outside.

`solid_contain`'s module doc says the door is "a signed count, not bare
parity": the side is the sign of the first nonzero running count, and
`point_in_solid`'s doc says multi-shell bodies "answer correctly by the
signed count". So that one example is wrong as stated. Whether the
reason stands is not known: the other readers named on that PR (the
signed volume, the seamed classification) were not checked on a
self-crossing solid.

## What it needs

One self-crossing solid (a loft through a figure-eight section will
do), read by each reader the ruling's reason names: point in solid, the
volume, the Boolean's classification, the mesher. Say which disagree
and how. If none does, the reason on PR 6301 is wrong and Ev should be
told before it is quoted again (PR 7068's first decision quotes it);
the promise may still be wanted for other reasons, and that is Ev's.
