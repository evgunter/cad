**Creating a thing and editing it are one implementation.** Ev
(chat, 2026-11-01): every node kind with a create form and an edit
panel has two implementations, and the rule is one for the whole
viewer, with (a) preferred — *a create gesture commits the node and
the node's edit surface takes it from there*, so every change made
while creating it is an ordinary edit that undo reaches. The add-profile
form is the instance Ev hit first; the extrude and revolve forms,
which take no variables, are the next; the seated tools follow.

One row is a profile-language question Ev raised on the same ground:
a profile step cannot refer to the profile's own earlier points.
