A valid body is drawn, and drawn as coarsely as its δ allows. Two
questions about one set of lanes (`crates/mesh`: curved, trimmed,
NURBS): **reach**, a face that builds, passes the tiers and measures
but that no lane meshes; and **sizing**, the density a lane emits and
the theorem that says it is enough (`crates/mesh/README.md`,
`[mesh.sizing]`). They are one track because each new arm of a lane
owes its sizing theorem in the same change, and the sizing rows read
the same lattice and chord code the reach rows extend.

Slate and posture: `work/tesslane/plan.md`; narrative in
`work/tesslane/log.md`.
