## The claim

`boolean::ops` hands `Body::merge_coplanar_faces_declared` **every** surviving declared `Rest` pair, whatever its carrier:

```rust
// crates/topo/src/boolean/ops.rs — declared_surface_pairs
(result.get_surface(ka).is_some() && result.get_surface(kb).is_some() && ka != kb)
    .then_some((ka, kb))
```

but that door is a COPLANAR merge and takes planes only:

```rust
// crates/topo/src/merge_faces.rs:635
Some(_) => Err(MergeCoplanarError::InvalidDeclaration {
    surface: k, what: "declared surface is not a plane",
}),
```

So a mate whose declared `Rest` pair sits on a CYLINDER, and whose faces both survive into the result, refuses `Merge(InvalidDeclaration { what: "declared surface is not a plane" })` — a door complaining about its caller's argument, in a message aimed at a user who declared something perfectly legal.

## How to see it

`crates/sweep/tests/r1_probes_m9_3.rs::probe_partial_engagement_never_silent` — a peg reaching halfway up its through-bore, planar + cylindrical `Rest` declared. Before the MATE-2 fix it refused earlier, in the reduction (`CurvedPierceUnsupported`), and never reached F7. With the reduction's covered rung repaired it gets through and lands here. Partial engagement is what makes it reachable: full engagement consumes both wall patches, so no cylindrical pair survives to be offered.

## Two shapes

1. **Filter at the caller**: `declared_surface_pairs` drops non-planar pairs, because a coplanar merge has no use for a carrier declaration it cannot type. Cheap, but it silently declines to merge two surviving co-carrier cylindrical faces — which may be work that genuinely wants doing, and the skip would be invisible.
2. **Give the merge stage a curved arm**: a declared-equal cylindrical pair whose faces are adjacent on one carrier merges the way a coplanar pair does. Real work, and the honest one if (1)'s skip turns out to matter.

Either way the probe's allow-list should come back down; it currently names this refusal explicitly so the frontier stays visible rather than silent.
