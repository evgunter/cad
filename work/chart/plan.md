## Order

**The region rows are one question.** The pole row, the round-hole row,
exact-region cells and the cone/sphere/torus windows all ask what a face's
region description on its chart IS. Today it is a chord polygon with
envelope boxes, read by a parity walk. That description has no answer
across a chart singularity, covers a round hole's whole disc, and keeps a
boundary collar. One designer pair weighs the description before any of
the four is built. The arms rows ride the same pair because the
cone/sphere/torus windows need their arms answered first:
`three-tables-of-the-chart-arms`, `angular-arms-…` and `certified-arms-…`
are one unit.

**In parallel, the rows that are not that question:**
- `normalize-without-the-length-question-two-more-sites`: a reproduction is
  in hand;
- `chart-inversion-is-spelled-three-times`: D3 names the end state;
- `chart-bound-outer-span-decides-a-poisoned-margin`: the row says its
  third reading may be a fork about what the recording scalar may be
  asked, so its lane checks that first and stops if it is one.
