## Closed by delegation to S52's home (2026-09-15, PR 2650)

`sweep::test_support::loft_prism(tol)` / `loft_prism_at(zs, tol)` /
`loft_prism_sections()` and the `PRISM_SQUARE` / `PRISM_TRAPEZOID` /
`PRISM_Z` constants. Twenty of twenty-four sites delegate; no golden,
sidecar or stored bit moved, verified by running them.

**The population was 24, and the row's own failure repeated four
times.** The count history is **11 → 18 → 21 → 23 → 24**. The row
opens by dissecting its first miss — a grep piped through `head -20`,
the truncation read as the population — and every later census was
defeated in turn:

- **18 → 21** (orchestrator, this session): three sites the row's
  enumeration never named, minted in the two weeks after it was filed.
  The row predicted exactly that growth.
- **21 → 23** (the lane): two sites the `-1.375` pattern cannot see,
  because they spell it `let d = 0.375;` and build `-1.0 - d`. A
  **regex** miss.
- **23 → 24** (the reviewer): `docs/GUIDE.md`, which lofts the same
  square and trapezoid at degree 2 with its own `d = 0.375` derivation
  — and **executes**, through `crates/pncad-py/tests/test_guide.py`.
  A **path** miss: the row's sweep, the dispatch and the lane's all ran
  over `crates/ demos/ tools/ scripts/`, and `docs/` was never in the
  set. Nobody re-derived the path list; each inherited it.

That last one is the finding worth keeping. Three of the four misses
were the search **pattern**; this one was the search **scope**, and a
scope is invisible in a way a pattern is not — a wrong regex returns
odd-looking results, a wrong path list returns clean ones. Both sweeps
are now re-run as `git grep` over every tracked file **with no path
argument at all**, which is the only form of this sweep that makes no
path claim.

**Four sites are deliberately not converted**, each for a reason that
is about what the site is for:

- `crates/step-import/tests/review_probes_m7_3.rs` — an independent
  restatement is the test's teeth.
- `demos/tour/src/skinned.rs` — the demos rule: a tour scene is
  evidence about the public API from an outside consumer's seat, and
  `test_support` is `#[doc(hidden)]` and dev-only.
- `crates/pncad-py/tests/test_north_star.py` — downstream of the tour's.
- `docs/GUIDE.md` — a public-API page written for a reader who has just
  met `Node.loft`; showing a `#[doc(hidden)]` dev-only door would teach
  a spelling the reader cannot use. The rustdoc example at
  `crates/sweep/src/skin.rs` stays for the same reason.

**Their guards are self-consistency guards, and the PR says so.** An
earlier draft claimed "no unguarded divergence was left standing"; the
reviewer perturbed the home's trapezoid and found `step-import` fully
green — the tripwire is `step-export`'s `committed_fixtures_are_byte_golden`,
one crate away. So nothing lands silently, but none of the four
unconverted copies reddens on divergence **from the home**, and that is
intended: a tripwire binding a demo to a kernel-internal fixture is what
the demos rule forbids.

**The variation was placement, not constants.** All 24 build the
identical trapezoid. Six sites keep the sections rather than the solid —
three because they vary the placement (a negation, a 1:2 re-spacing) and
three because they need the pre-body artifact the solid discards
(`Lofted`'s wall and cap keys, `loft_geometry`'s output, a
`(sections, places)` pair carried beside a second section set). One door
for both would have hidden the first three.

**X4, caught by review:** the unit added `stacked_at` — a **seventh**
spelling of "translate by z" — into the shared home, in a commit whose
own X4 section credited it for not minting a second `quad`. Resolved by
making it the only one: five byte-identical private `at_z` deleted,
`common::stacked` delegating. Seven bodies → one. The unit also wrote a
hand-written numeric census into the module header thirty lines below
the paragraph explaining why this module keeps none; both counts are
gone and the header describes the shape instead.

**The standing question, answered well.** `perf12_census_bvh_diff` reads
*better* with the named constants than with the literals, and
`d9_mesh_goldens` keeps its name, module and the `patch_memo.rs`
contract with only the body delegating. At `lib_u3_sections` — whose
subject is that the prism is built from profile-vocabulary sections —
delegation did cost the site its claim, so the row now reads the
sections back and asserts three one-loop quads with every bulge exactly
`0.0`. Falsified before commit: a `0.01` bulge in `quad_section` reddens
it.
