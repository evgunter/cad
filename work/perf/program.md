The performance program: a standing register of unbuilt performance
work, advisory beneath `docs/DESIGN.md` (its ratified parts live there
as the D9 addendum: parallelism idioms and the GPU boundary), and since
2026-09-10 an orchestrated program that measures where a GUI user, a
kernel user and a developer actually wait, files each pain point as an
item, and dispatches the fixes. `plan.md` ranks the open cost centers by
payoff, confidence and effort, keeps `benches/` and `docs/perf-data/`
as the measurement record, and expires its own claims — re-check a
cited `file:line` before quoting a cost as current. `log.md` is the
narrative. Posture (Ev, in-chat, 2026-09-10): algorithmic wins and
"stop doing this" over "do this faster"; nothing that costs clarity or
makes a refactor harder; code that is very new is deprioritized; a fix
lands in whichever program's territory holds the cost, announced in the
log, with the owner's in-flight units checked first; a change of the
"stop doing this" kind — one that removes work a ratified clause asks
for — goes to Ev as an `[ev]` PR before it lands.
