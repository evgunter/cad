## Lessons carried from AUTHOR

Every one of AUTHOR's sixteen units minted some duplicate — a hand copy
of a kernel string, a second home for a rule, a parallel test builder —
and every review caught it. Spec each unit against it. Re-verify a fix
pass's correctness before merging: AUTHOR's fix passes twice
introduced a real regression (a fused-entry start drawing a close
nobody wrote; a silent `unwrap_or_default` collapse). Run
`cargo test -p editor-core --test all node_standing::` before merging
a viewer unit that reads evaluations, and run any ε-sensitive sketch
row at `CAD_TOLERANCE_EPS=1e-6` and `1e-12` too: a viewer-only diff
never selects the ε rows in the per-PR gate.
