## Order

**The four header rows first, as drive-bys, not as a unit** — three
sentences the code has outgrown, a DAG paragraph that disagrees with
its fold, a `# Freezing` claim, and item docs carrying unit
archaeology. Whoever opens `sym.rs` for anything else takes them on
the way past.

Then `symbolic-tier-costs-95-percent-of-the-m10-3-drive`: 20.8x
measured is the number that decides whether anything else on this
slate is affordable, and it is measured already.
`sym-rs-is-one-file-with-a-347-line-header` is the row that makes the
rest workable and should be weighed against DECIDE's live lanes before
it lands — a 3898-line file split under an open lane is a merge
conflict by construction.

The three frontier rows are P2 and are conversations before they are
units; they serve `docs/DESIGN.md`'s error-propagation reach goal
rather than anything shipping.
