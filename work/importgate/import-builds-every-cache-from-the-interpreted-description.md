The build half of D7's interpretation stage, as ratified on PR 7074: interpretation at the file's band picks a description for every surface, edge and vertex; the kernel builds every cache from it and certifies at ε; no value the file printed becomes a cache. It stacks on `importgate/interp-layer` (PR 7091: the file band, the refusal vocabulary, placements, one record, the move ledger) and carries the type split that unit deferred (`step-import-evidence-and-interpretation-are-one-type`), because a description type that holds no file carrier cannot land without the build that replaces the carrier.

## Scope

- **Two types.** The file's statements (carriers, `t0`/`t1`, vertex points, records) as *evidence*, readable only by interpretation readings and the move report; the interpreted model (topology, kernel surfaces, per-edge description, per-vertex incidences) as a type with no field a file digit could occupy as a cache. `assemble`, `adopt` and the normalizations take the interpreted model.
- **Selection at the file band.** Which description an edge is — `Intersection { pair, selector }` (the selector a native edge holds), `TangentIntersection`, a seam or wrap, a surface's own iso, a conventional chart image, a curve inside one surface — is decided by the kernel's readings at the file band, the file's curve only choosing the component. The ladder that certifies the file's carrier at ε to choose goes. `line_column_match` and promotion read one dial.
- **The build.** Carriers from the kernel's constructions (`pair_section`/carry, the closed forms, boundary isos, the surface's own seam locus, the mapped chart image); each vertex where its built carriers meet transversally, else the foot of the file's point on its one carrier; parameters by the construction's own inverse. Certified at ε through the doors a native build uses. Every move beyond rounding reported on the ledger.
- **Refusals.** An edge whose description the kernel cannot construct refuses not-yet-supported, naming the pair or kind and the lane (no file-curve fallback). Build refusals read as at a native build. The set-ε-to-ε_in stopgap retires: D4 ¶1's sentence, `crates/geom-core/README.md`'s stopgap and at-rest departure, `FileCoincidence::miss_recourse_in_file`'s residual sentence (a wording change that follows the ratified D7, PR 7074).
