## What

`boolean::boxes::edge_axial_span`'s conic arm projects an arc onto an arbitrary axis by `ARC_SAMPLES` samples plus the 1-D sagitta charge, where the exact extremum exists in closed form: the per-coordinate body of `geom::curves::boxes` — `c ± √((a·û·n)² + (b·v̂·n)²)`, admitted when `atan2` of the pair lies in the span — generalized from a coordinate axis to a unit direction `n`. The boolean lane's `axial_window` has the ordering to read it; the census mirror (`face_reach`) does not, so the same two-arithmetics rule as the edge box applies (`EdgeBoxRule`'s conic bullet). `geom` would grow the directional door first — Track N's ground; file that half there when this is taken.
