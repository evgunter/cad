## Spec for the "no usable value" member (2026-09-29, EDIT orchestrator) — branch `edit/node-standing-one-type`

**Tier: single review (one Opus FULL).** The member retypes a
vocabulary that nine doors and the Python tags read, and it touches one
serde-persisted enum. Correctness is at real risk; the idea is one.

**The blocker is gone.** This member was held on "a persisted format".
BOOL-13 (PR 1553) removed that blocker before release: a format change
is a corpus regeneration. The only persisted carrier is `RunStatus`,
serialised in the ε-audit's cross-process JSON (`VerdictSummary`). No
committed corpus or golden file holds it.

**The finding, re-measured (orchestrator's survey, `origin/main` after
PR 3164).** "A node has no usable value" is read off `eval.nodes` in
nine places, not five, plus two stringly sites:
- `resolve/mod.rs` ~1544 (`ResolveIndeterminate`);
- `resolve/hit.rs` ~230 (`standing()` → `HitTestError`'s three arms,
  which `NodePickError::Standing` and the name doors carry);
- `resolve/vdiff.rs` ~227 (`RunStatus`, serde; its hash bytes are
  hand-pinned at ~636);
- `eval/mod.rs` ~3078 → `appearance.rs` ~393 (`AppearanceLossCause`,
  whose `TargetNotEvaluated` has no node);
- `names/interrogate.rs` ~473 (`InterrogateError`);
- `product.rs` ~880 (`ProductError::RootFailed`/`RootPoisoned`, and the
  `ProductErrorKind` mirror);
- `pncad/src/export.rs` ~140 (`ExportError`);
- `pncad-py/src/py/value.rs` ~1147.

The stringly sites are:
- `names/geompred.rs` ~452 (`SelectRefusal::NotADatum { found: &'static str }`
  folds "failed", "poisoned", "unevaluated" and "wrong payload" into a
  string, losing `through`);
- `stackup.rs` ~747 (a comparison label).

Collapsing sites also fold the triple:
- `clearance.rs` ~2247;
- `names/select.rs` ~659 and ~730, and `names/mod.rs` ~148, which
  return an empty list silently;
- `eval/wire.rs` ~637;
- `Evaluation::value`;
- `drive.rs` ~1205;
- `mc.rs` ~363.

Every one of these is a hypothesis: verify each against the tree before
building on it, and report any correction.

**The ruling.**
1. **One type, one home.** A node's standing is one type in `eval`: not
   evaluated, failed at `node`, poisoned at `node` through `through`.
   - It is read by one function on `Evaluation`, which answers the
     node's value or its standing.
   - Every door above that reads a node's result goes through it.
   - A door's refusal carries the standing as a payload; it does not
     re-spell the three arms.
   - `RunStatus` is `Ok`, `Absent` or the standing's kind, derived from
     the same function. Its serde words and its hash bytes do not move.
2. **The standing names itself.**
   - Its `Display` names the standing (which node, what state, where
     the repair is) and no door.
   - Each door's refusal prefixes its own subject.
   - The recourse tail that three sites hand-sync word for word today
     is the type's own.
   - This closes `work/edit/the-standing-ladder-speaks-as-a-hit-test-at-every-door`:
     `NodePick::build`, `build_all` and the name doors stop saying
     "hit test:" for a standing refusal.
3. **No fail-quiet.**
   - `SelectRefusal::NotADatum` splits into "no value" (carrying the
     standing) and "wrong payload kind" (carrying the kind), so
     `through` is no longer lost.
   - Each collapsing site either carries the standing, or states in
     one line why collapsing is right there. For example, `stackup`'s
     comparison label and a guard that only asks "is it Ok".
   - The `names` queries that return an empty list for a node with no
     value either refuse with the standing, or document why "no names"
     and "no value" are the same answer to their caller. Decide per
     site and say which.
4. **Stable words.**
   - The Python tags (`hit_test_error_tag`, `node_pick_error_tag`,
     `resolve_indeterminate_tag`, `interrogate`'s, `product`'s) keep
     their words.
   - The binding reads the standing once, where it can.
   - `RunStatus`'s JSON shape does not change.
   - Any Display text a test pins is re-baselined and named.
5. **Docs.** The comments that call the hand-sync deliberate
   (`resolve/mod.rs` ~1087–1098, `interrogate.rs` ~138) are rewritten to
   the new shape.

**Rows.** Each is red on `origin/main`, then green.
- A census: every door that reads a node's result either goes through

- A poisoned target reaching `NotADatum` carries `through`.

- The name doors and `NodePick::build` do not say "hit test" for a
  standing.
- `RunStatus` round-trips its JSON unchanged, and its key bytes are
