## Ruled and spec'd (2026-09-29, EDIT orchestrator) — single review

**Tier:** single review, one Opus FULL. The unit changes the stable Python
tags' source and a public enum; the risk is a tag that moves.

**The premise has moved.** The row's live consumer was
`PartFault::PartRootFailed` carrying prose. It is gone: PR #3459 typed it
as a `NodeRefusal` (an `Arc<NodeErrorKind>`). What remains is the row's
first half:
- `NodeErrorKind` has no class projection;
- `pncad-py`'s `node_error_tag` (tags.rs ~831) is a hand-written
  parallel match over its arms.

**Ruled:**
1. **The projection.** Add `NodeErrorKind::kind() -> NodeErrorClass`, a
   fieldless `Copy + Eq + Hash` enum with one variant per arm, following
   the in-tree precedent exactly: `ProductErrorKind`
   (`product.rs` ~455–560) and `BooleanErrorKind`.
   - `kind()` matches exhaustively, so an arm added to the error reds it.
   - A test-module exhaustive visit over the class reds a phantom variant.
   - The two blends get two classes (`Fillet`, `Chamfer`), because the
     tag already splits on the verb. Every other tag-level split a
     payload carries today becomes its own class the same way.
   - Nothing else in the payload is read.
2. **The tag.** `node_error_tag` becomes a match over `NodeErrorClass`.
   Every tag word stays exactly as it is: they are stable API. A census
   row pins, for one witness per arm, that the tag on this head equals
   the tag on `origin/main`.
3. **"One declaration for both mirrors" (the row's open question):
   decided, no macro.** A hand mirror guarded both ways (`kind()`
   exhaustive, plus the phantom visit) is the ratified precedent for
   `ProductErrorKind` and `BooleanErrorKind`. A macro would be the
   workspace's first for this. The row's worry was that the phantom
   direction goes red only downstream; the in-crate phantom visit closes
   it. Apply the same guard to `NodeErrorClass`.
4. **Consumers that substring-match `NodeErrorKind` prose.** Sweep for
   them: tests, the viewer, the census. Move each one that is
   classifying, not reading the words, onto `kind()`.

**Rows** (red on `origin/main` where the thing did not exist, then green):
- the class census (one witness per arm → class → tag, equal to main's
  tag);
- the phantom visit;
- a planted arm with no class that fails to compile, recorded in the PR
  body.

**Seams:** LIB owns `pncad-py`'s `tags.rs`, its census and the stubs, if
the class is projected to Python (optional; say which). The live EDIT
lane `standing-fix` touches `eval/mod.rs` and `tags.rs`; merge
`origin/main` when it lands.

## Built (2026-09-29)

PR #3469. `NodeErrorKind::kind() -> NodeErrorClass`
(`crates/editor-core/src/eval/class.rs`): fieldless, `Copy + Eq + Hash`,
101 variants over 71 arms. One variant per arm, and one per value where
the published tag already split an arm: the blend verb (`Blend` and
the three selection refusals), the placement-rule fault, the carried
frame direction's fact, the instantiation fault (with the seam fault
inside it), and the mate fault. `kind()` is exhaustive over the arms and
every split value. The in-crate phantom visit is `witness(class)`,
exhaustive over the class, walked over a declaration-ordered `ALL`,
with `witness(c).kind() == c`.

`pncad-py`'s `node_error_tag` takes the class. Every word is unchanged:
101 rows composed against `origin/main`, 0 differ, and pinned by
`node_error_tags_are_the_published_words`. `part_fault_tag` is gone.
The seam classes delegate to `resolve_fault_tag`, and the mate and
placement words are held word for word against their other maps.

The row's open question is decided as ruled: no macro, a hand mirror
guarded both ways. Not projected to Python, because
`EvaluationError.kind` already is the class. Ten consumers that
classified by `Debug` or `Display` text now read `kind()`; the PR body
has the hit list. The doors that render the kind to prose are WIRE's
`node-error-kind-has-no-fieldless-projection`, which gained this
unit's evidence and a fourth door (`eval::leaf::read_leaf`).
