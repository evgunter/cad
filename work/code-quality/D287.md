### S172. The "is this line code" test that is still spelled outside the shared home

**[verified]** Raised by #834's style review over its own new guard. The textual guards that walk a crate's own sources each carry their own answer to *is this text code or comment* — `trim_start().starts_with("//")` — and each inherits the same blind spots: a `/* … */` block, a `#[doc = "…"]` attribute, the needle inside a string literal or a `macro_rules!` body, and any code that FOLLOWS a comment on the same line.

**The home exists and is not the question.** `code_only` blanks comments and literal bodies while preserving byte offsets and line structure, and is pinned on all four shapes above plus the one a naive quote scanner breaks on (a lifetime, `&'a str`, which must not open a char literal). `test_utils::source` is where it lives for the repo; `topo::fixtures::code_only` is the in-crate one.

**What is outside it:** `topo/src/review_d18_probes.rs:273` (`trimmed.starts_with("//")`, re-derived 2026-09-01; the line was `:263` when this was raised).

**The class is the finding, and the walk was already consolidated.** Guards in `topo/src` share `fixtures::crate_sources()` (`chord_join.rs:2490`, `pcurves.rs:1621`, `review_m1_pr5_internal.rs:323`, `sector_shape.rs:508`, `review_d18_probes.rs:252`, and two rows in `face_normal.rs`) — the style review counted eight; it is seven, and its `chord_join` line number is six lines off. `fixtures.rs:74` says outright that *"a guard against duplication should not be the next copy of its own walk"*, which is the argument for the predicate as much as for the walk.

**Why it is not cosmetic.** A guard whose comment test is wrong is green for the wrong reason. `face_normal.rs`'s inventory pins that file at **zero** reads of `Face::sense_sign` while the file names the method five times in `//!`/`///` prose — the whole zero rested on one prefix test, so a single block comment in that file would have reddened its own guard.

**Scope:** one remaining instance, `topo/src/review_d18_probes.rs:263`, which is Track P's `D261`. The scheduling question this row posed — whether a home is minted or the predicate copied twice more — is answered: `test_utils::source` is the home, with three views of a file plus the traversals and balanced-text operations that read them, and `crates/test-utils/tests/reader_census.rs` is the ledger of what still sits outside it.
