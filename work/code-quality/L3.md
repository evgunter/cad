## What

The remaining `S35` roll-up rows — the Tier-2 table of smaller findings
across `editor-core`, `topo`, `geom-brep`, `step-import`, `profile`,
`geom`, `mesh` and `bvh` that no track row names individually. `S35`
carries the table.

## Why last

Lowest value density; several will be resolved incidentally by the
tracks. The table spans every track's territory, so it is partitioned
into rows on the owning tracks as each is taken, and what is left when
the tracks empty is this unit.
