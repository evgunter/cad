## What

`S38` — comment trimming, to what is actually necessary, under the
code-comment tests in `memories/cad-working-style.md`: keep a comment
only if something would go wrong without it. `S38` carries the
population and the extreme cases; `S37`'s 473 plain-`//` internal
comments carrying milestone codes are this pass's too.

## Why last

Must follow every deletion on every track; trimming comments on code
about to be deleted is pure waste. Note the pressure runs the other way
too: fix passes add prose when a finding demands a claim-site reason
that did not exist. It is a workspace-wide comment sweep, so it
collides with every track and goes after the tracks empty (ordering
rule 1: decide before you delete; delete before you polish).
