## What

**A described control net carrying poison gets a PARTIALLY poisoned answer, and the finite lanes still decide (filed by CERT-N2; a wrong answer, not a style row).** The class has two members and one of them is fixed: a net poisoned in one channel folds to a box (or a min/max hull) that is poison on that axis and FINITE on the others, and every consumer of it tests axes independently. **Member 1, FIXED in `geom` by CERT-N2** — `geom::surfaces::boxes::nurbs_surface_aabb` and its curve twin now screen on poison ANYWHERE and answer the poison box, which repairs `topo/src/boolean/boxes.rs:879`'s `FaceBoxRule::ControlNet` arm (and through it `boolean/ops.rs:1677,1760,1916` and `separation.rs:161,416`) with no edit on this track's ground, because they all call that door. **Member 2, OPEN and this row** — `topo/src/census.rs:1708`'s `ControlNet` arm folds `min`/`max` over the net itself and answers `Some((lo, hi))`. The consequence is not merely that a sign gets decided: the census's own margin ladder reads the finite axes, marks the pair *cleared*, and does **not** push `CensusUndecidable` — so a partially poisoned box CLEARS an interference pair in the **permissive** direction, and the far-containment arm goes silent. `census.rs:1694-1722`'s 29-line comment argues, for the placeholder, that folding poison would give a box that is *"neither a claim nor a refusal"* and answers `None`; the guard it argues behind is `is_placeholder`, which reads every channel since `S99` closed, so the fold now takes the masquerade the comment was written to keep out. The arm wants its own poison test — `geom`'s `net::any_poison` is the question a box asks, and its docs carry why it is wider than the state discriminator. Construct the net with `NurbsSurface::new` over control points whose every `x` is NaN; `geom/tests/net_placeholder_width.rs` mints one and executes the box half.
