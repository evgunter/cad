The bindings' housekeeping, split from the DOORS that LIB keeps — Ev's
call, in chat: the north-star half is medium priority and the rest is
low, and holding both in one slate meant the low half set the pace.

What is here: stubs that pin names but not signatures, so the options
census's stub-to-door link is unchecked; `pncad.pyi` declaring three
attributes on a class that ships seven; tags minted at the boundary
that are outside `TAG_INVENTORY`'s reach, so nothing pins their values
or sees them collide with a kernel word; prose counts of populations
the code holds; and four doc sentences describing a tree that moved.

Two rows are P1 and are the reason to read this slate rather than
skim it: `BlendVerb` and `ShellVerb` coincide field for field (the
generic correspondence waiting for its third instance), and
`persist_err` is a **319-line function projecting 14 arms through a
15-slot positional tuple**, where a transposed pair is invisible.

Almost everything else is class `E` and is drive-by material for
whoever is next in the file (`work/README.md`, "The tracker is not
comprehensive").
