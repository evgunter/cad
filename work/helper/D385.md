### The one member the row describes wrongly

`geom-brep/tests/review_m5_pr3_e2e.rs` no longer lifts through
`T::from_f64`. It rebuilds the control net through **`Dual64::constant`**
inside `f9_enum_arm_nurbs_circle_locus`:

```rust
.map(|p| Point3::new(Dual64::constant(p.x), Dual64::constant(p.y), Dual64::constant(p.z)))
```
then `NurbsCurve3::new(n64.knots().clone(), ctrl_d, n64.weights().to_vec()).unwrap()`.

Same class, same `new(..).unwrap()` tail, different lifting function —
so the natural replacement is `NurbsCurve3::map_scalar(Dual64::constant)`,
not `map_scalar(T::from_f64)`. **A `from_f64` sweep will miss it**, and
the row's own instrument is a `from_f64` sweep.

### The retain/retire criterion is unchanged and still applies per file

CERT-N1's exemption — reviewer-authored batteries whose independence from
`map_scalar` is their stated regression value — still sorts the twelve
the way the row sorts them: `topo/tests/fixture/mod.rs`,
`profile/tests/common/mod.rs` and the two `*_replay` files are fixtures;
the rest are batteries. `review_m5_pr3_e2e.rs` is the clearest RETAIN
candidate under that criterion — it is the M5 PR 3 review's own probe
that the enum arm lifts a payload correctly, so a version of it written
through `map_scalar` would be testing the thing it is testing with.

### What my sweep could not match

I swept for `from_f64` inside the twelve named files and for `map_scalar`
across all test targets. **Not swept**: other spellings of the same class
elsewhere in `crates/*/tests/` — a lift through `Dual64::constant` (as
above), through `T::from_f64` inside a closure bound to another name, or
through an `Interval::exact`-style constructor. The one such spelling I
found, I found by opening a file the row already listed, not by pattern;
so this enumeration is a **FLOOR of twelve** and the class is very
probably larger. Establishing the real population wants a sweep over
`NurbsCurve[23]::new|NurbsSurface::new` call sites in test targets whose
argument is a freshly `.map()`ped control vector — which I did not run.
