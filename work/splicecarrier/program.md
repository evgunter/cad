A spline (NURBS) edge reaches the boolean's later doors since SPLICE's
curve × face table, and several of them ask the carrier for something
only an analytic carrier answers: a parameter for a point
(`Curve3::param_near`), a period, a run-on along the curve. The join
cannot run a kept edge on along it, a meeting the boundary pass found
on it has no split parameter, the flush rule's track reads every point
as off it, and the touch floor reads its arc at the carrier's whole
speed bound. One mechanism, a parameter inverse a spline carrier
does not have, sits under all of them.

**Witness:** teapot wall 3 (the spout onto the pot), which stops at
`PointSplitCarrierUnsupported`
(`a-meeting-on-a-spline-boundary-edge-has-no-split-parameter`).

Opened from SPLICE, whose log (`work/splice/log.md`) carries the
history of every row here. This track owns the NURBS carrier's parameter inverse: `Curve3::param_near` and its callers.
